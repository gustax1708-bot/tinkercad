RASCUNHO INFORMATIVO — REVISÃO NECESSÁRIA ANTES DE USO REAL

Termos e condições

Este texto é um rascunho descritivo para o protótipo educacional CUIDA+. Não é aconselhamento jurídico nem um contrato final. O responsável pelo projeto deve revisar e completar identificação, contato, jurisdição e condições comerciais, se aplicáveis, antes de uso público.

Última atualização: 26 de novembro de 2026.

Finalidade

O site demonstra telas e fluxos de um sistema de telemetria vestível. Algumas informações podem ser simuladas e a API local depende da configuração do operador.

Não é um dispositivo ou serviço médico

O protótipo não tem validação clínica, não oferece diagnóstico, tratamento, monitoramento de emergência ou garantia de entrega de alertas. Não use seus dados para decisões de saúde e não dependa dele para pedir ajuda. Em uma emergência, use os serviços locais apropriados.

Uso e dados

Use apenas dados demonstrativos. Perfil e rotina de medicamentos são salvos localmente no navegador; telemetria pode ser gravada no banco local do operador. A limpeza ou perda do armazenamento pode apagar esses dados. Consulte a política de privacidade.

Disponibilidade e limitações

O site, simulador, firmware e API são fornecidos para demonstração e podem estar indisponíveis, incompletos ou apresentar leituras incorretas. O alerta depende da conexão, configuração de rede, dispositivo e serviços externos envolvidos.

Responsabilidade e conteúdo

Não introduza segredos, senhas ou informações de saúde reais. Não tente acessar sistemas ou dados de terceiros. O responsável pelo projeto deve definir regras finais de suporte, responsabilidade e tratamento de dados antes de oferecer o sistema como produto.
