RASCUNHO INFORMATIVO — REVISÃO NECESSÁRIA ANTES DE USO REAL

Política de privacidade

Este documento descreve, em linguagem simples, o funcionamento atual do protótipo CUIDA+. Não é uma política legal final. O responsável pelo projeto deve revisar e completar os dados de contato, retenção e operação antes de qualquer uso público ou com dados reais.

Última atualização: 26 de novembro de 2026.

Que dados o protótipo usa

  • O perfil de demonstração (nome e e-mail), medicamentos, horários, preferências de acessibilidade e lembretes são guardados no armazenamento local do navegador deste dispositivo.
  • No modo local, a API pode receber telemetria enviada pelo dispositivo ou simulador: leituras de pulso, SpO₂, temperatura, bateria, movimento, eventos de queda ou pânico, identificador do dispositivo e horário de recebimento. A API grava esses dados no banco SQLite local configurado pelo operador.
  • O protótipo não sincroniza perfil ou medicamentos entre dispositivos. A versão estática publicada no GitHub Pages não hospeda a API nem o banco de telemetria.

Onde os dados ficam

Os dados do perfil e da rotina ficam no navegador e podem ser apagados limpando os dados do site no próprio navegador. No modo local, o operador controla o computador, o arquivo SQLite, os backups e a retenção da telemetria. Não há prazo de retenção configurado pelo site.

Cookies, armazenamento e analytics

Este protótipo não tem ferramenta de analytics nem cookies de publicidade configurados. Ele usa armazenamento local do navegador para funções demonstrativas. Fontes e ícones podem ser carregados de Google Fonts e unpkg; esses provedores recebem as requisições necessárias para entregar os recursos.

Compartilhamento e serviços externos

O GitHub Pages hospeda a versão estática e os provedores de fontes/ícones entregam recursos externos. No modo local, a telemetria é enviada à API escolhida pelo operador. Não insira informações pessoais ou de saúde reais neste protótipo.

Segurança e solicitações

Tokens da API devem permanecer em configuração de servidor ou arquivo local ignorado pelo Git, nunca no HTML ou JavaScript público. Como este projeto ainda não tem um canal público de privacidade nem um responsável legal informado, esta versão não recebe solicitações formais. Esse canal precisa ser definido antes da publicação como serviço real.

Uso experimental

O CUIDA+ é um protótipo educacional. Suas leituras e alertas não são validados clinicamente, não substituem avaliação médica, supervisão ou serviços de emergência e não devem orientar decisões de saúde.
